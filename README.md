# Zombie Game

A 2D zombie survival game created for my first-year university JavaScript module.

## Features
- Single player game
- Player and enemy health system
- Different types of difficulties in the settings menu
- Shop where a player can buy skins with better melee damage
- Soundtrack that can be increased or decreased in the settings menu
- Incrementing difficulty with each new levels

  ## Controls
  - WASD keys OR the right, up, down and left arrows for movements 
  - Holding shift while using any of these keys for sprinting
  - Space-bar for attacking enemies

 ## Languages used 
 - JavaScript
 - HTML
 - CSS
